## Capture convention / 今後の撮影方針

Keep the mouse pointer and its highlight out of published screenshots. Prefer moving it outside the captured window. If the capture tool overlays its last pointer position, crop only unused margins and preserve every relevant control and canvas object. Inspect the saved file before publication.

公開用のスクリーンショットには、マウスカーソルとそのハイライトを写しません。原則は撮影範囲外へ移してから撮影します。ツールが直前のカーソル位置を重ねる場合は、必要な操作部品と描画内容をすべて残し、空白の余白だけを除外します。保存後の画像を目視確認してから掲載します。
